==============================================================================
R1.1 VERDICT
==============================================================================
  The path `moov/udta/meta/ilst/<key>/data` resolves to a `data` box,
  which is a PAYLOAD CARRIER inside the ilst ITEM box that is the
  declaration object. Three findings make them non-equivalent:
    (a) the ITEM box is the declaration; `data` is inside it;
    (b) the `data` body is NOT the value - an 8-byte prefix precedes it;
    (c) `meta` is a FullBox, so the path alone does not fix the offsets.
  Identity of the REPORTED declaration is therefore NOT established by
  the path alone. Value identity (R1.3) and encoding (R1.6) must carry
  part of it, and the address grammar must decide whether the item box
  or the data box is the addressed object.

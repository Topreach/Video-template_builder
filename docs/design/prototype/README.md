# Clickable UI Concept

Open [index.html](index.html) in a browser to walk through the mobile workflow concept.

This is a standalone HTML/CSS/JavaScript prototype with no framework or package install. It does not read local videos, call APIs, run AI, save projects, create accounts, purchase subscriptions, or render media. Buttons simulate interactions or explain deferred capabilities.

The prototype is intended to review navigation, section triage, replacement suggestions, profile/settings, and the preview/confirmation sequence before production frontend work. Styling and content are not final brand decisions. The interaction requirements are maintained in the [mobile frontend design specification](../mobile_frontend_design_spec.md).
